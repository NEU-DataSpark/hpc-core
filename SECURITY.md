# Security Policy

## Reporting a vulnerability

Do **not** open a public issue for a security problem. Use GitHub's private vulnerability
reporting for this repository (the "Report a vulnerability" button under the Security tab).
Include a description, reproduction steps and the affected version or commit. Do not include
credentials, tokens, host names, account names or any other personal or cluster data in a report.

## Scope

Only the `main` branch and the most recent tagged release are supported.
